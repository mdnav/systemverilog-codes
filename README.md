# 📖 Overview

**SystemVerilog Codes** is my dedicated hardware design repository focused on learning and implementing **SystemVerilog** for digital circuit design, RTL development, simulation, verification, and FPGA-oriented development.

The repository contains practical SystemVerilog implementations covering fundamental digital logic, combinational circuits, sequential circuits, registers, counters, finite state machines, memory concepts, testbenches, and verification techniques.

The primary objective is to strengthen my understanding of **Digital Design, RTL Coding, Hardware Verification, and FPGA Development** through consistent hands-on practice.

This repository documents my learning journey toward developing professional skills in **VLSI Design and Verification**.

# 🎯 Repository Goals

The main goals of this repository are to:

- Master SystemVerilog fundamentals.

- Practice simulation and waveform analysis.
