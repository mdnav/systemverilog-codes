# 📖 Overview

**SystemVerilog Codes** is my dedicated hardware design repository focused on learning and implementing **SystemVerilog** for digital circuit design, verification, and FPGA development.

The repository contains structured RTL implementations, simulation examples, verification testbenches, and practical digital design projects covering everything from basic combinational logic to advanced sequential circuits and hardware verification concepts.

This repository documents my journey toward becoming a professional **VLSI Design & Verification Engineer**, emphasizing clean RTL coding practices, reusable testbenches, and industry-standard hardware design methodologies.
